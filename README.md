# 📚 Library of Vermundi

An ASP.NET web application inspired by an original epic-fantasy setting.
Built as the term project for two ASP.NET courses, the application evolved from a content-driven site into a multi-feature platform with a structured domain model and real-time communication features.

---

## 🌍 Story Premise (Context)

The story is set in the Empire of **Thasharith**, a vast world-spanning civilization that once fought a devastating war against demonic forces. Ancient warriors banished the demons to their own realm, but the peace came at a cost: the spirit of the Demon King was bound into the imperial succession, ensuring that he rules briefly in each generation rather than conquering the world outright.

In the current era, demons are considered myth. The present emperor — the current incarnation of the Demon King — is quietly consolidating totalitarian power while introducing rapid technological advancement powered by forbidden magic.

A small group of scholars and warriors remembers the truth.

The **Library of Vermundi** is their attempt to preserve suppressed knowledge and secretly organize resistance.

This website represents that in-universe archive.

---

## 🎯 Project Overview

The Library of Vermundi is a database-driven ASP.NET application featuring:

* 📖 A structured article database for world lore
* 🔎 Categorization and relational content modeling
* 🧩 A layered domain model with multiple related entities
* 💬 A secure discussion/chat feature for in-universe collaboration
* 🛡️ Role-based access and user management

The project was developed over two academic terms, with the second term significantly expanding the domain complexity and interactive features.

## 🏗 Domain Model

The application includes:

* Articles (library entries)
* Categories / Tags
* Users
* Comments or Discussion Threads
* Chat/Message entities (introduced in the second term)

The second phase of development required:

* More complex relationships
* Navigation properties
* Structured data modeling
* Expanded business logic

This evolution mirrors the in-universe growth of the resistance network.

---

## 💬 Chat / Resistance Network Feature

To satisfy the second-term requirement for a more complex domain model, a secure communication feature was added.

In narrative terms:

> A hidden channel for citizens to discuss suppressed knowledge and coordinate resistance.

In technical terms:

* Persistent chat entities
* User-linked messages
* Relational message storage
